Surgery Tools

Surgical Sponge

Used to clean up the operation site and make it easier to see. It is the only usable tool when the message "You can't see what you are doing!" is shown.

Surgical Splint

Used to fix fractures. If the patient has a broken bone, use this to fix it.

Surgical Antiseptic

Used to clean the operation site. If the operation site is unsanitary, this can be used to make it clean. If the operation site has incisions or is bleeding and is unsanitary, a fever will start

Surgical Antibiotics

Used when the patient has a fever. If the patient's fever is climbing, this can be used to lower the temperature. The patient's temperature cannot be lower than 98.6.

Surgical Anesthetic

Used to put a patient to sleep, turning its Awake status to Unconscious. Surgical Scalpel must only be used when the patient is not awake.

Surgical Scalpel

Used to cut open the patient. The "Fix it" button will usually appear once the patient is diagnosed and enough incisions are made. It is also used to access shattered bones so that Surgical Pins can be used. Every use of scalpel causes slightly more bleeding.

Surgical Stitches

Used to decrease bleeding and close up incisions. This tool is usually used when the patient is losing blood before a Surgical Scalpel has been used or after the "Fix it" button when the player's incisions need to be stitched up.

Surgical Lab Kit

Used to unlock Surgical Antibiotics. Surgical Antibiotics cannot be used before using this tool.

Surgical Clamp

Used to clamp up blood vessels. This tool can be used to decrease blood loss, but it can only be used if the patient has at least one incision. Less effective than Surgical Stitches.

Surgical Pins

Used to fix shattered bones. When used, a shattered bone turns into a broken bone. This item can only be used when the patient has at least one incision.

Surgical Transfusion

Used to transfuse several pints of blood into a patient. Increases the strength of the patient's pulse, which is an indication of how much blood the patient has.

Surgical Ultrasound

Used to diagnose a patient. If the root cause is not a fever, the player must use this to discover the patient's condition. It will also reveal the number of broken and shattered bones.

Surgical Defibrillator

Used to shock a patient back to life. If the patient's heart has stopped, this must be given to the patient within 2 moves or the patient will die and the surgery will fail.

Surgical Sponge

Used to clean up the operation site and make it easier to see. It is the only usable tool when the message "You can't see what you are doing!" is shown.
